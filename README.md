Entry for the make.fun competition "Monday Morning Punchlines": one joke about Monday mornings, at most 200 characters, judged pairwise on laughs.

The program writes the joke to `/output/entry.txt`.

> "My Monday alarm went off, apologised, and asked if we could both just pretend it's Sunday. Deal — we're still pretending."
